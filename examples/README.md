# FluentConfig Examples

Copy-paste Streamer.bot C# Execute actions. Use **Execute C# Method** with **Run on UI thread** enabled. Add GAC assembly references as in [docs/REFERENCES.md](../docs/REFERENCES.md).

| File | Description |
|------|-------------|
| **SimpleExample.cs** | Minimal: toggle, textbox, slider. This is the basis for the **Quick Start** action—paste into an Execute C# Method subaction (run on UI thread) with correct GAC refs, DLL check, and version check. |
| **MediumExample.cs** | Dropdown, slider, button, `ShowWhen` conditional visibility. |
| **CompleteExample.cs** | All controls: Toggle, Textbox, Slider, Button, Dropdown, PillInput, WithVisibility, dialogs, Toast, Log. Copy to explore the full API. |
