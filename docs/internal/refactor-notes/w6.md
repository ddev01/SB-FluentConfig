# W6 — Updater, versioning, dead wire

## What changed

- `IncludeSourceRevisionInInformationalVersion` is false on `Host.csproj`. `GitHubUpdater.Normalize` strips `+` build metadata before the digit filter so `0.1.0-beta.2+githash` no longer overflows to `0.1.0.0`.
- Deleted `update.stage` from host dispatch, `RpcMethods`, web `rpc.ts`, and `mockBridge`. Kept `GitHubUpdater.StageUpdate` as a host API (`UpdaterFlowTests` calls it directly).
- Removed `mode: 'self'` from the TS update-notice / `update.available` payloads (`mode?: 'notify'` only).
- `UpdatePrefsStore.Load` / `MarkChecked` / `IgnoreVersion` in `FluentConfigSession.Updates.cs` now key on `ScopeKey` (menu id), not `_title`.
- `IsAllowedDownloadUrl` + PE-reject + zip-not-dll + version-normalize tests in `UpdaterContractTests.cs`. Did not duplicate `GitHubUpdaterPickAssetTests`.
- `Redeploy.ps1` probes `STREAMER_BOT_PATH` → Desktop `Streamer.bot-x64-1.0.4` → WinGet, matching `Host.csproj`. Removed the single hardcoded 1.0.7 install path.
- `UpdateHelperLauncher` prefers the configuration matching the running assembly (Release path before leftover Debug).
- Host (and tests) `ProjectReference` the updater helper and copy the exe next to `FluentConfig.dll`. `UpdaterFlowTests` no longer shells out to `dotnet build`.
- Renamed `StartupPerformanceTests` → `SchemaBuildSanityTests` (schema-only, no 5s "perf" assert).
- Demoted `DurationParsing` / `DurationParsingTests`: experimental helper, not the UI/save grammar (`web/src/lib/duration.ts`).

## 0.2 breaking-change bullets

- Web → host `update.stage` is gone. The menu cannot stage a DLL; FluentConfig.dll updates stay on the copy-paste DllCheck action. `GitHubUpdater.StageUpdate` remains a host API.
- `UpdateAvailablePayload.mode` / update-notice `mode` is notify-only (`'self'` is not a legal value).
- Extension update prefs (`FluentConfig_UpdatePrefs_*`) key on the explicit menu id, not the window title. A title rename no longer orphans ignore/throttle state; an id change does.
- Installed InformationalVersion is `0.1.0-beta.2` without a `+githash` suffix. `minFluentConfig: "0.1.0-beta.2"` gates now see the real version.
