## Considered and rejected

- Mounting all tabs / `display:none`: every hidden tab's `onMount` would fire refresh and filepath.validate at bootstrap.
- Restoring an `out:` transition on the tab panel: Svelte keeps outroing nodes in the DOM (the two-pages-plus-scrollbar flash already removed).
- Moving the refresh decision table to the host: it needs the uncommitted store.
- floating-ui: ~2.3 KB of bundle headroom; not worth it.
- Popover API: WebView2 Chromium version is not guaranteed; `position: fixed` needs no extra API.
- A Twitch-reward-specific widget: addon is the primitive; Refresh (and later Browse/stepper) use it. Filepath Browse stayed a sibling flex, not a SelectMenu addon.
- Wiring `roundToStep` into `SliderControl`: `SliderNode` has no `step`. The helper is exported for later.
