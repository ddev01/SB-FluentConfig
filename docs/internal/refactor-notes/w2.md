# W2 — DSL builder hygiene

## What changed

### Phase 1 (commit `c184edf`)

- `Hint` / `Size` / `ShowWhen*` require an active control (no silent discard after `Flush`).
- `Size()` merges per axis; last token wins within an axis. Single-string form unchanged.
- `.MaxSelected` / `.DefaultIndex` / `.DefaultIndices` on a toggle without `.WithExclusive` throw at flush.
- `.DefaultIndex()` on a refresh-only dropdown throws and points at `.DefaultByValue`.
- `Default` / `Range` last-call-wins (int vs double) for number and slider.
- `SchemaValidation.AssertUniqueSaveKeys` walks the document (groups, RepeatFor, pills, `valueSaveKey`) and throws on duplicates.
- Generated group/button/connection ids uniquify via `FluentConfigSession.SchemaIds.cs` (`UniqueGeneratedId`).
- Slider without `.Range` no longer registers a default 0–100 range. `RepeatFor` cap is 32; `resolvedMax < startIndex` throws.

### Phase 2

- Deleted `SectionFluentWrapper` / `PanelFluentWrapper` / `FluentWrapperBase`. `Toggle()` returns `SectionBuilder` / `PanelBuilder` (CRTP).
- Added `When.On/Off/Eq/Neq/Cmp/All`. `ShowWhen(When)` / `WithVisibility(When, build, chrome?)`.
- Removed public `inverted:` from `WithVisibility`. `WithVisibilityWhenOff` remains as sugar.
- Leaf show-when-off: `ShowWhen(When.Off(key))` emits boolean `equals: true` + `inverted: true` (not string `"true"`).
- `When.All` emits nested groups. `ShowWhen(When.All)` throws (AND is not a leaf condition).
- `_saveKeyPath` was already unused and is gone (phase 1).

## 0.2 breaking-change bullets

- Naming wrapper types (`SectionFluentWrapper`, `PanelFluentWrapper`, `FluentWrapperBase`) no longer compiles. Authors who only wrote `s => s.Toggle()...` are source-compatible; this is a binary break.
- `WithVisibility(key, build, inverted: true)` is gone. Use `WithVisibilityWhenOff(key, build)` or `WithVisibility(When.Off(key), build)`.
- `.DefaultIndex()` on a refresh-only dropdown throws. Use `.DefaultByValue("...")`.
- Duplicate `saveKey` / `valueSaveKey` across a document throws at build.
- `RepeatFor` without a declared driver `.Range` throws (no implicit 0–100). Max above 32 throws.
- `.Hint` / `.Size` / `.ShowWhen*` after a structural call (`Intro`, `Separator`, …) throw instead of no-op.
